# furnitureStore

***Название:*** Сайт - магазин мебели <hr>
***Описание сайта:*** сайт магазина мебели предназначен для привлечения клиентов посредством информативного и удобного интерфейса. Включает главную страницу, страницы каталога товаров и корзины. <hr>
***Особенности сайта:*** 
1. **Соответствие макету:** все блоки расположены в соответствии с макетом.
2. **Кодировка и DOCTYPE:** кодировка документа установлена на UTF-8. Применен корректный DOCTYPE, позволяющий использовать современные HTML-теги, такие как "<article>", "<header>" и другие.
3. **Валидность:** код был проверен на наличие синтаксических ошибок с использованием статических анализаторов, таких как W3 Validator.
4. **Независимость блоков в CSS:** в проекте применена методология БЭМ. Каждый блок реализован как независимая единица, элементы являются составными частями блоков, а модификаторы изменяют внешний вид блоков и элементов.
5. **Семантика кода:** каждый HTML-тег используется в соответствии с его назначением. <hr>

***Использованные технологии:***
1. HTML5, CSS3 (Flexbox, Grid);
2. Git и GitHub для контроля версий.
